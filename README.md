# react-training-base-project-BAW
Base project and playground for learning React with a modular architecture approach. This project applies MVVM-inspired structure to React using JavaScript, aiming to improve maintainability, scalability, and code handover by enforcing clear separation between UI, logic, and data layers.

This repository is created as a learning environment for React and JavaScript, using MVVM and modular architecture.
Instead of following the common unstructured functional approach often seen in React projects, this project emphasizes:

- Clear separation of concerns (UI, ViewModel, business logic)

- Modular folder structure

- Predictable data flow

- Improved readability and maintainability

The goal is to make React projects easier to scale, easier to maintain, and safer to hand over to new developers, especially those coming from structured frameworks like Flutter.

This repository serves as:

- A React learning playground

- An experiment in applying MVVM-like patterns to React

- A reference for developers who prefer structured architecture over ad-hoc functional composition


## Why This Project?

While React encourages functional programming and hooks, large projects can become difficult to maintain when:
- UI and business logic are tightly coupled
- Folder structures lack clear responsibility
- Architectural conventions are not enforced

This project explores how MVVM and modular thinking can be adapted to React to improve long-term maintainability.
